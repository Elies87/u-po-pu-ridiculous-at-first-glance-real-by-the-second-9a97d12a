## The pitch

> We rent emotional-support goats to burned-out tech offices, because companies happily pay $800 a month for a goat that cuts sick days better than any wellness app.

One sentence, 163 characters. It sounds like a joke — renting goats to offices — until the second look: the buyer is a tech company already spending on employee perks, the price ($800/month) sits inside a normal wellness budget, and the payoff is concrete (fewer sick days), which is exactly how a CFO justifies it.

## How it works

`main.py` is Python 3, standard library only. It writes the pitch sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), as UTF-8 text, one line plus a trailing newline. The output is fully deterministic: the sentence is a fixed string in the source, so running it twice produces byte-identical files.

Run it:

```sh
python3 main.py
```
